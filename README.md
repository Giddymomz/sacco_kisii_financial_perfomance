# Influence of Financial Investment Decisions on Financial Performance of SACCOs in Kisii County, Kenya

**Author:** Gideon Mogendi Momanyi
**Status:** Research Proposal — In Progress (2026-2027)
**Proposal Year:** 2027
**Study Area:** Kisii County, Kenya

## About This Project
This repository contains my research proposal on how financial investment decisions affect the financial performance of registered Savings and Credit Cooperative Societies (SACCOs) in Kisii County, Kenya.

This is a writing sample / research proposal for graduate applications for Fall 2028.

## Research Objective
To examine the influence of financial investment decisions on the financial performance of registered SACCOs in Kisii County, Kenya.

## Specific Objectives
1. To determine the effect of credit investment decisions on financial performance
2. To examine the effect of capital investment decisions on financial performance
3. To assess the effect of liquidity investment decisions on financial performance
4. To determine the effect of portfolio investment decisions on financial performance

## Variables
Dependent Variable (Y):
- Financial Performance — measured by Return on Assets (ROA), Return on Equity (ROE), and loan repayment / growth

Independent Variables (X):
- X1 = Credit Investment Decisions
- X2 = Capital Investment Decisions
- X3 = Liquidity Investment Decisions
- X4 = Portfolio Investment Decisions

## Conceptual Model
Y = b0 + b1X1 + b2X2 + b3X3 + b4X4 + e

Where:
Y = Financial Performance
X1 = Credit Investment Decisions
X2 = Capital Investment Decisions
X3 = Liquidity Investment Decisions
X4 = Portfolio Investment Decisions
b0 = Constant
e = Error term

## Methodology
- Design: Descriptive survey design
- Target Population: Registered SACCOs in Kisii County, Kenya
- Data Collection: Structured questionnaire (5-point Likert scale) + SACCO financial records
- Analysis: Descriptive statistics, correlation, and multiple linear regression
- Tools: Python (pandas, statsmodels), Excel / SPSS
